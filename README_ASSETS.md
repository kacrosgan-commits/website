# Dark + Purple Marketing Agency Asset Pack

Copy the `public/assets/` directory from this ZIP into the root of your existing Cursor project, merging with the existing `public/assets` directory. Open `CURSOR_PROMPT.md`, copy its text into Cursor Agent, and ask Cursor to use `ASSET_MANIFEST.json` to wire up every file.

The kit includes: 3 original high-resolution imagery assets, 7 sample portrait files, 8 fully scalable section background SVGs, 6 scalable demo case-study illustrations, 3 scalable blog illustrations, and 10 SVG marketing service icons. All SVGs are standalone image files with no baked-in UI text. Total: 37 visual assets.

The original pack included seven sample portraits named `team-01.webp` through `team-07.webp`. The live site uses nine later files, `member-01-founder-ceo.webp` through `member-09-qa-devops-engineer.webp`. Seats 01–04 are owner-supplied photographs. Seats 05–09 are illustrative portraits and must not be presented as verified employees. Service case studies and blog illustrations are generic design artwork, not evidence of client work.

The large rendered design sheets are not used as website components. Cursor must implement typography, sections, buttons and forms as actual accessible HTML/CSS/TS rather than slicing screenshot UI.
