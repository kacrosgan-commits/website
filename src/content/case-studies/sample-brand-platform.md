## Challenge

This sample shows how an AI case study can be written without inventing accuracy numbers. It is not a client project.

A company wants people to ask questions of documents they already have. The source material, the permissions, and the cases the system must refuse are not defined yet.

## Solution

The sample approach would name the task, the document set, and the refusal rules before connecting a model.

## Architecture

Retrieval over an approved document set, with the answer path kept inside the existing product. The model provider would be chosen in the proposal.

## Features

A question box, source citations, and a visible failure when the document set does not contain an answer.
