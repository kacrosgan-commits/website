## Challenge

This is a sample page for backend work. It is not a record of an API in production.

Two products need the same business rules and are starting to copy them. There is no shared contract.

## Solution

The sample approach would put the rules behind one API, document the contract, and move the clients onto it in a planned order.

## Architecture

An API, a database, and the two clients that call it. Performance work would follow measurement, not a guess.

## Features

The core resources, authentication, and error responses the clients can handle.
